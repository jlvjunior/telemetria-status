    Como funciona

    1. A cada 15 minutos, um job agendado do GitHub Actions acessa cada serviço e mede o tempo de resposta.
    2. Resposta abaixo do limite = operacional; acima = lento; uma falha = instável; duas falhas seguidas = fora do ar, e um incidente é aberto.
    3. O resultado é gravado no repositório e o pipeline publica o painel atualizado no Cloudflare Pages.
